Bootstrap: A CSS framework

Bootstrap is a free and open-source CSS framework directed at responsive, mobile-first front-end web development. It contains HTML, CSS and JavaScript-based design templates for typography, forms, buttons, navigation, and other interface components. It is one of the most popular front-end frameworks in the world, enabling developers to build visually appealing and highly functional websites quickly and efficiently.
